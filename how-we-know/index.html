How we know

This atlas reads frozen extracts, never a live map. Each page uses one release of its data and never mixes two, except What the Map Can't See, whose subject is the gap between two sources: it sets the volunteer map's latest year against one commercial download. Every number you see is computed from a file in this repository, and the table for each map below names that file, the release it comes from and how the number was counted.

Two sources feed the maps. Overture Maps is a commercial-grade open dataset that merges several providers into one list of places, with a category for each. OpenStreetMap is a map drawn by volunteers: streets, wards, rivers and the buildings between them. Neither is a census, and both miss the stall that has no sign. The last map in the atlas says what that costs. Place data: Overture Maps Foundation, CDLA-Permissive-2.0. Streets and boundaries: © OpenStreetMap contributors, ODbL.
