Inside old Ward 25, 239 of the 1,725 listings that write one of its three D-streets, by either name, still write the code name. Across the district, 4 in 5 doors that name a ward still give its old number.

Inside old Ward 25, 239 of the 1,725 listings that write one of its three D-streets, by either name, still write the code name: D1, D2 or D3. Each street is painted from its west end: the share that writes the code name in the first colour, the rest in the second.

In 2025 the district's numbered wards were redrawn as named ones (Nghị quyết 1685/NQ-UBTVQH15, 16/6/2025). Listings that name a ward are counted by door, the first line of the address, so many listings at one door count once: 1,159 of 1,455 doors still give an old ward number. The fainter lines paint each street with enough such doors the same way.

Of the 719 listings that gave an old ward in April and are still listed in October, 10 gave a new ward name. The old wards and the new are drawn on one map. → Twenty wards, then five, p. 12
